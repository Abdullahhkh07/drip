## HOW TO USE THESE TEMPLATES

### Auto-Reply Setup:
1. Open WhatsApp Business
2. Go to **Settings** → **Tools** → **Auto-Reply**
3. Enable it
4. Paste template #1
5. Customize with your details

### For Manual Messages:
1. Copy template above
2. Paste into WhatsApp
3. Replace {{VARIABLES}} with actual data
4. Send to customer

### Variables to Replace:
```
{{NAME}} = Customer name
{{ITEMS}} = List of items ordered
{{TOTAL}} = Total price
{{ADDRESS}} = Delivery address
{{ORDER_ID}} = Order ID (you generate)
{{DAYS}} = Delivery days estimate
{{DATE}} = Date
{{TRACKING_NUMBER}} = Courier tracking
{{COURIER_NAME}} = Delivery company name
```
